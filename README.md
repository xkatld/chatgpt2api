项目更新内容

更新要点汇总

1. 核心交互与设置修复
- 设置页改动追踪修复：增加初始配置判空防护，彻底解决配置未加载时的空指针异常。
- 代理输入即时响应：脏值判定直接监听代理输入框文本变化，输入或粘贴代理地址后即刻点亮保存与撤销操作。
- 代理测试并发提速：多代理检测由串行等待升级为全并发异步处理，毫秒级反馈可用状态与网络耗时，并加入单项异常兜底。
- 操作状态异常修复：修复图库与设置按钮因状态判断缺陷导致的常态禁用问题，确保各交互按钮状态正常。

2. 模型服务与网络调度增强
- 模型列表兜底降级：号池为空或账号异常时自动提供基础模型列表兜底，并支持模型列表强制刷新。
- 多代理随机轮询调度：支持在设置页配置多行代理地址，请求上游时自动进行随机调度分配。

3. 自动化发布工作流优化
- 原生自动化流水线：规范化触发键名配置，主分支推送直连触发平台构建流水线。
- 容器镜像自动发布：主分支代码更新后自动打包双架构镜像并推送最新标签至容器镜像仓库。
